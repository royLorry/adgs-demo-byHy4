## 关键能力速览

- **6 维度规则体系**：完整性 / 准确性 / 一致性 / 及时性 / 唯一性 / 有效性 + 埋点质量专项。
- **3 类规则定义**：模板型 / SQL 型 / 对比型，统一编译为执行计划。
- **质量左移**：rule-gateway 部署在 S3 采集网关侧做实时校验（Schema/类型/值域/必填），源头拦截 ≥ 70%。
- **卡点与熔断**：与 S4 调度深度集成，Block 级失败阻断下游；S8 不可用时 fail-open 事后补检。
- **异常聚合 + 降噪**：指纹聚合 + 抑制窗口 + 升级机制 + 渠道降级，有效告警率 ≥ 90%。
- **影响面驱动定级**：调 S7 血缘计算下游影响面，参与严重等级判定。
- **数据回溯闭环**：Backfill → S4 推导下游 → 完成后强制复检 → 复检通过才关单。
- **埋点质量专项**：覆盖率 / 丢失率 / 重复率 / 属性填充率 / 端侧失败率 5 项指标。
- **资产质量分**：6 维加权 → 输出至 S1 健康分的"质量"维度。
- **自举治理**：S8 自身 100% 纳入 ADGS 自身治理（NFR-15）。

## 服务模块（详见 SDD §2）

```
┌─ rule-admin ─────────── 规则 CRUD + 版本 + 模板市场 + 灰度
├─ rule-compiler ──────── 规则编译（SQL/模板/对比 → IR → 执行计划）
├─ audit-engine ───────── 稽核执行引擎（调度/执行/状态机/卡点判定）
├─ anomaly-hub ────────── 异常中心（聚合/去重/影响面/定级/工单）
├─ alert-center ───────── 告警与降噪（渠道/抑制/升级/熔断）
├─ backfill-svc ───────── 数据回溯（推导下游/审批/状态/复检）
├─ track-quality ──────── 埋点质量专项（5 项指标）
├─ quality-portal ─────── 质量门户（看板/规则市场/排名）
├─ qscore-service ─────── 资产质量分（6 维加权 + 输出至 S1）
└─ rule-gateway ───────── 部署在 S3 网关的实时校验（Schema/类型/值域/必填）
```

## 关键架构决策（SDD §14 ADR 摘要）

1. **三类规则统一 IR + 编译为执行计划**（ADR-S8-01）。
2. **质量左移**：rule-gateway 在 S3 网关内联校验，fail-open 兜底（ADR-S8-02）。
3. **异常必须先聚合 → 去重 → 定级 → 抑制再告警**（ADR-S8-03）。
4. **严重等级三档**（Block/Warn/Info）固化处置矩阵（ADR-S8-04）。
5. **与 S4 深度集成实现卡点与回溯，回溯结果强制复检**（ADR-S8-05）。
6. **质量分仅贡献 S1 健康分的"质量"维度**，避免重复计算（ADR-S8-06）。
7. **稽核结果分区化 + 冷归档 + 异常长保留**（ADR-S8-07）。
