## 关键能力速览

- **元模型底座**：L0 元元模型 / L1 元模型 / L2 元数据实例三层，支持无代码扩展新资产类型。
- **全域分类体系**：主题域（9 个）+ 数据分层（6 级），构成资产 `(主题域, 分层)` 二元组分类坐标，注册即强制。
- **三类元数据采集**：技术（自动增量 CDC + 全量对账）/ 业务（人工 + 评审）/ 操作（访问与热度）。
- **资产目录与检索**：中文 IK + 拼音全文、多维过滤、热度/健康分加权排序，P95 ≤ 500ms / Top5 命中 ≥ 85%。
- **关系图谱**：表级 + 字段级（S/A）血缘与依赖，5 分钟内变更可见。
- **合规扫描**：LR-1~LR-5 跨层依赖规则自动化，阻断/告警分级处置。
- **资产健康分**：6 维加权（质量/时效/热度/文档/分类/SLA），周期 + 触发增量重算。
- **自举治理**：S1 自身 100% 纳入 ADGS 自身治理（NFR-15）。

## 服务模块（详见 SDD §2）

```
┌─ meta-api ─────── 对外 API 网关（CRUD/批量/订阅/鉴权/限流/审计）
├─ meta-collect ─── 元数据采集引擎（Hook/CDC/全量对账/漂移检测）
├─ meta-classify ── 分类与合规引擎（命名推断/LR 扫描）
├─ meta-search ──── 资产检索（中文 IK + 拼音 + 多维过滤 + 排序）
├─ meta-graph ───── 资产关系图谱（邻居/路径/子图导出）
├─ meta-audit ───── 审计与版本（不可变事件/版本快照/diff/回滚）
├─ classify-admin ─ 分类体系管理（主题域/分层/变更评审/灰度）
├─ health-score ─── 资产健康分（6 维加权 + 周期 + 触发重算）
└─ meta-portal ──── 资产目录门户（搜索/详情/关系图/订阅/反馈）
```

## 关键架构决策（SDD §13 ADR 摘要）

1. **三存储最终一致**：关系库（写）+ 图库（关系）+ 检索引擎（检索），CDC 同步（ADR-S1-01）。
2. **分类体系定义权归属 S1**：而非 S5（ADR-S1-02）。
3. **分类坐标注册即强制**：自动推断 + 人工确认（ADR-S1-03）。
4. **资产回滚双人复核** + 全量留痕（ADR-S1-04）。
5. **采集：人工元数据优先于自动采集**（ADR-S1-05）。
6. **Meta Change Event 是跨存储一致性与对外通知的唯一机制**（ADR-S1-06）。
7. **健康分 6 维加权 + 周期全量 + 触发增量**（ADR-S1-07）。
