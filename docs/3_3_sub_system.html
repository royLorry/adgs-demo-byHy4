3.3子系统依赖关系图

14 个子系统的 26 条依赖，按平面内依赖与跨平面依赖两类组织。治理面在左侧呈一条纵向依赖链，其内部的 S1 → S7 → S8 → S9 → S14 → S1 构成治理自闭环；跨平面依赖则成对出现（管控下发 ↔ 元数据回流）。

治理面内部依赖与闭环
S1→S7→S8→S9→S14→S1 治理自闭环；S1→S2/S6/S7/S11 S1 作为元数据底座向各治理子系统供给事实源。
跨平面 · 管控下发
治理面 → 数据面/消费面：事件契约、脱敏策略、质量卡点、主题域与分层规范、生命周期策略、指标口径与权限策略。
跨平面 · 元数据回流
数据面 → 治理面：上报质量数据、管道血缘、模型血缘、建模产物。任一管控下发均有对应回流路径，避免"治理空转"。
链路过滤 交互：悬停任意子系统可高亮其全部入向/出向依赖，其余连线淡出。
治理闭环走廊跨节点的内部依赖以弧线绕行，避免压盖中间子系统
